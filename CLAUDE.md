# Сайт internet-kanevskoy.ru — правила проекта

Статический сайт «Интернет рядом» + несколько PHP-скриптов в `api/`.
Хостинг sprinthost, заливка по SFTP скриптом `deploy.js`.

## Публикация

- **Пуш в GitHub сайт НЕ обновляет.** На хостинг — отдельной командой:
  - `node deploy.js файл1 файл2 …` — только указанные файлы (так и надо в обычной работе);
  - `node deploy.js --all` — все файлы репозитория.
- Доступ к хостингу — `.deploy/credentials.json` (в git не попадает).
- `deploy.js` только **загружает и перезаписывает** файлы. Ничего на сервере не удаляет.
- Тарифы и оборудование — `data/*.json`, потом `node build.js` (см. README-TARIFFS.md).

## Данные на сервере — НЕ ЗАТЕРЕТЬ

Эти файлы создают и пополняют сами скрипты **на сервере**. Настоящая версия есть
**только на хостинге**, в git и в локальной папке их нет (и быть не должно):

| Файл на сервере | Что внутри | Кто пишет |
|---|---|---|
| `api/baza-data/baza.json` | База бригад: коды домофонов в МКД, телефоны сотрудников, оборудование и цены | `api/baza.php` (приложение «Контроль слежения» и страница `/baza/`) |
| `api/stats-data/stats.json` | Анонимная статистика приложения «Сойка» | `api/soyka-stats.php` |

Правила:

1. **Никогда не заливать эти файлы с компьютера.** `deploy.js` пропускает их сам
   (список `NEVER_UPLOAD`, там же и этот `CLAUDE.md`), даже при `--all` и даже если указать явно. Если добавляется
   новый скрипт со своими данными на сервере — добавить его файл в `NEVER_UPLOAD`,
   в `.gitignore` и в таблицу выше.
2. **Не удалять и не пересоздавать папки** `api/baza-data/` и `api/stats-data/` на хостинге
   (в том числе через панель sprinthost или SFTP-клиент). Заливать в них можно только `.htaccess`.
3. **Менять формат записей осторожно.** `baza.php` читает старые записи как есть;
   новые поля добавлять так, чтобы записи без них оставались рабочими.
4. **Перед переездом на другой хостинг или большой переделкой** — сначала скачать живые файлы
   с сервера (тем же доступом из `.deploy/credentials.json`) и сохранить вне репозитория.
   Резервная копия базы бригад есть и на каждом телефоне с приложением (кэш), но кэш —
   не замена файлу на сервере.

## Ключи доступа (в git не попадают)

- `api/baza-key.php` — общий пароль бригад к `api/baza.php`. Копия пароля —
  `D:\Проекты\Приложения\_keys\.baza-internet-kanevskoy.pw`.
  Смена пароля: поменять в обоих местах → `node deploy.js api/baza-key.php` →
  сообщить новый пароль всем бригадам (лично, не в общий чат).
- `api/stats-key.php` — ключ просмотра статистики «Сойки».

Эти файлы на сервере уже есть. Если локальной копии нет (новый компьютер, свежий
клон) — `--all` их просто не зальёт, серверные останутся. **Не создавать пустые
или «временные» версии этих файлов и не заливать их** — это сломает доступ всем.

## База бригад (с 13.10.2026)

- Разделы (type): `door` — домофоны, `person` — сотрудники, `equip` — оборудование
  (цена для абонента, бонус за штуку при 1–4 / 5–8 / >8 шт.). `olt` — какой BDCOM/порт обслуживает дом
  (только адрес и порт, без данных абонентов; Новоминская заполнена по выгрузке биллинга 25.09.2026,
  BDCOM определён по подсети IP: 192.168.128.x — 1-й … 192.168.133.x — 6-й). Порты Новоминской — по таблице портов BDCOM.
  `muff` — муфты VSOL с координатами (Новодеревянковская, Сладкий Лиман, Вольный — по списку муфт),
  дома этих станиц тоже в `olt` с OLT вида «VSOL04», портом и муфтой в поле `cab`. Каталог заведён по приказу 179-П;
  при новом приказе цены правятся в приложении или на `/baza/` — у всех обновится само.

- `api/baza.php` — API: заголовок `X-Key: <пароль>`; `GET` — вся база;
  `POST {"items":[…]}` — добавить/изменить по `id`, удалить — `"del": true`
  (пометка удаления хранится 180 дней, чтобы удаление дошло до всех телефонов).
- `api/baza-data/.htaccess` — запрет чтения папки из браузера (заливать можно).
- `baza/index.html` — страница для коллег без приложения, вход по тому же паролю.
- `/baza/` и `/api/` закрыты от поисковиков в `robots.txt` и заголовком `X-Robots-Tag`.
- Клиент в приложении — репозиторий permswitch, файлы `Baza.kt`, `BazaActivity.kt`
  (адрес API там зашит: `https://internet-kanevskoy.ru/api/baza.php`). Если меняется
  адрес или формат — обновить и приложение.
