Политика конфиденциальности приложения «Сойка — помощник абонента»

Здесь описано, какие данные хранит и передаёт Android-приложение «Сойка — помощник абонента» (пакет su.soyka.cabinet). Коротко: ваши личные данные остаются в телефоне, автору уходит только анонимная статистика.

1. О приложении

«Сойка — помощник абонента» — независимое приложение для абонентов интернет-провайдера «Сойка» (ООО «Фирма Связь»): вход в личный кабинет, оплата, проверка домашнего интернета, связь через мессенджер МАКС. Приложение не является официальным приложением провайдера. Автор — Артём, контакты ниже.

2. Что хранится только в телефоне

Эти данные приложение сохраняет на вашем устройстве и автору не передаёт:

  • логин и пароль от личного кабинета — чтобы входить автоматически;
  • лицевой счёт, баланс и тариф из личного кабинета;
  • ФИО, телефон, адрес подключения и населённый пункт — из личного кабинета или вписанные вами;
  • история проверок интернета.

ФИО, телефон, адрес и результаты проверок попадают к получателю, только когда вы сами отправляете сообщение в МАКС: приложение готовит текст, а отправляете его вы.

3. Анонимная статистика

Чтобы автор понимал, сколько людей пользуется приложением и какие разделы нужны, приложение отправляет на сайт internet-kanevskoy.ru только счётчики событий по дням: установка, запуск, первый вход в личный кабинет, запуск проверок и разделов, версия приложения.

В статистику не входят ФИО, телефон, адрес, лицевой счёт, логин, пароль, идентификаторы устройства или рекламные идентификаторы. Сервер не сохраняет IP-адрес вместе со статистикой. По этим счётчикам невозможно определить, кто именно пользуется приложением.

4. С какими сервисами связывается приложение

  • Личный кабинет провайдера (fs.soyka.su) — вход, баланс, оплата;
  • Яндекс.Диск — проверка и загрузка новой версии приложения;
  • сервисы определения внешнего IP (api.ipify.org, ifconfig.me, ipinfo.io) и Яндекс Интернетометр — при проверке интернета;
  • Сбербанк, мессенджер МАКС, банк для перевода автору — только когда вы сами открываете их из приложения;
  • internet-kanevskoy.ru — анонимная статистика (раздел 3) и форма заявки на подключение.

Эти сервисы получают обычные технические данные любого подключения (например, IP-адрес) и обрабатывают их по своим правилам.

5. Разрешения

  • Интернет и состояние сети — для работы кабинета и проверок;
  • Геолокация — по желанию: Android показывает название Wi-Fi сети только приложениям с этим разрешением. Своё местоположение приложение не определяет и никуда не передаёт;
  • Установка приложений — чтобы установить скачанную новую версию. Android каждый раз спрашивает подтверждение.

6. Как удалить данные

Все данные удаляются вместе с приложением или кнопкой «Очистить данные» в настройках Android. Накопленная анонимная статистика ни с кем не связана, поэтому удалять в ней нечего.
